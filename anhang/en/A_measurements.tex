\section{Reference-relative evaluation}\label{sec:measurements:reference}

The figures below relate all measured values to \emph{one} reference. That reference is a measured
axis value of the corpus itself (default \texttt{search\_algo}/\texttt{linear\_scan}) and expressly
\emph{not} an external library baseline: a measured \texttt{std::map} performance series does not
exist, because every \texttt{std::map} in the corpus is the conformance oracle of the test dock and
thus a correctness, not a performance data point. If the reference does not occur in a measurement
series, the figures of this section are omitted without substitute.
